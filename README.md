# Арканоид — PyGame Edition

![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)
![Pygame](https://img.shields.io/badge/Pygame-2.6+-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)

Классическая игра **Арканоид**, написанная на Python с использованием PyGame. 10 уникальных уровней с красивой графикой, частицами, бонусами и звуковыми эффектами.

![Gameplay Screenshot](screenshot.png)

## 🎮 Особенности

- **10 уровней** с уникальными темами и узорами блоков (Радуга, Огонь, Лёд, Лес, Золото, Космос, Неон, Закат, Океан, Тьма)
- **Красивая графика**: градиенты, частицы, шлейф за шариком, блики, звёздное небо
- **5 типов бонусов**: расширение платформы, мультибол, доп. жизнь, замедление и ускорение шарика
- **Звуковые эффекты**: полностью программная генерация звука через Web Audio
- **Система очков** с сохранением рекорда
- **15-секундные временные бонусы** скорости с визуальными индикаторами
- **Меню выбора уровня** с мини-превью узоров блоков
- **Один EXE-файл** — не требует установки Python

## 🕹️ Управление

| Клавиша | Действие |
|---------|----------|
| ← → | Движение платформы |
| ↑ ↓ | Выбор уровня (в меню) |
| ПРОБЕЛ / Enter | Старт / подтверждение |
| ESC | Возврат в меню |

## 📦 Установка и запуск

### Вариант 1: EXE (Windows)
Скачайте `Арканоид.exe` из вкладки [Releases](https://github.com/USERNAME/arkanoid-pygame/releases) и запускайте.

### Вариант 2: Исходный код

```bash
# Клонирование репозитория
git clone https://github.com/USERNAME/arkanoid-pygame.git
cd arkanoid-pygame

# Установка зависимостей
pip install pygame

# Запуск игры
python arkanoid.py
```

## 🔨 Сборка EXE

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name Арканоид arkanoid.py
```

Готовый EXE будет в папке `dist/`.

## 📝 Описание бонусов

| Буква | Цвет | Эффект | Длительность |
|-------|------|--------|--------------|
| W | 🟢 Зелёный | Расширение платформы | Постоянно |
| M | 🟠 Оранжевый | Мультибол (×3) | Постоянно |
| + | 🔴 Красный | +1 жизнь | Постоянно |
| S | 🔵 Синий | Замедление шарика (×0.7) | 15 секунд |
| F | 🔴 Красный | Ускорение шарика (×1.4) | 15 секунд |
